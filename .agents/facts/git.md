# Git facts

- Default branch: `main`.
- Repository changes use `feature/<short-description>` branches and pull
  requests; never implement directly on the remote default branch.
- Commits are focused around one coherent behavior, foundation, documentation,
  or workflow change.
- Update roadmap, facts, changelog, and release governance in the same change
  when they explain implementation or policy changes.
- No Git remote is configured yet. Remote setup and repository settings require
  explicit owner/repository scope before mutation.
